# Figma baseline

This directory is a read-only capture of the `web design` file (`aaJEv2Z8j6HaegMHou4N09`) used as the Phase 1 visual-intent source.

## Captured reference endpoints

- Home/work desktop: `83:251`
- Home/work mobile: `11:31`
- Who desktop: `502:466`
- Who mobile: `638:432`
- Write desktop: `532:1208`
- Write mobile: `640:448`
- Expanded control panel: `1:1039`
- Compact control panel: `1:2899`

`reference-nodes.json` contains the captured node geometry, layout settings, and variable bindings for those endpoints. Matching PNG renders are in `screenshots/`.

## Captured system inventory

- 10 Figma pages in `file.json`
- 6 variable collections in `variable-collections.json`
- 119 variables split across `variables/`: 11 primitives, 6 semantic colors, 48 spacing/grid variables, 32 type-scale variables, 9 typeface variables, and 13 UI-state variables
- 71 component/component-set records in `components.json`
- Page inventories for Who, Write, both library pages, Draft, Interactive, and the Touchbaes page

The full-file and full Home-page traversal exceeded the Figma bridge's request window and returned HTTP 504. Phase 1 therefore retains the complete approved Home endpoints, screenshots, variables, components, and the other page inventories, while recording the unavailable full Home tree as a scoped capture limitation. No Figma node, variable, component, or file was changed.
