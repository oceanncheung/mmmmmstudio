# Round 69 reconstructed archive scope

The `round-69-gold` tag is a retrospective archival Git root reconstructed
from the immutable snapshot in `cargo/gold/round-69/`.

It truthfully contains the canonical Cargo source, shared partials, validators,
test mirrors, and manifest preserved when Ocean approved Round 69. Those files
are projected into their canonical `cargo/` paths in the archival commit.

It is not a complete historical checkout of the entire MM.S workspace. The
Round 69 archive did not capture:

- the complete creative-source archive;
- Figma file state or revision history;
- Freight's complete asset inventory;
- raw Cargo draft or public HTML readbacks;
- all embedded-app working directories;
- generated `home.html`, `who.html`, and `write.html` bodycopies.

For that reason, Round 69 is not represented as the literal Git parent of
Round 80. It remains a separate immutable comparison and rollback reference.
